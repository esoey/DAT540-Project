# DAT540-Project
Project 1: Explainable Machine Learning for Gallstone Disease

## Requirements

- Python 3.10 or newer
- Jupyter (Notebook, JupyteLab or VS Code with Jupyter extension)
- The following Python packages:
  - pandas
  - numpy
  - scikit-learn
  - matplotlib
  - seaborn
  - shap

  (Or run `pip install -r requirements.txt`)
 
- Data file:
  - `dataset-uci.csv` (The UCI Gallstone dataset, 319 patients, 38 features)
  - Keep dataset in the same folder as `project_gd.ipynb`
